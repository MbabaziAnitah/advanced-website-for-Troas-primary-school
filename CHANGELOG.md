# Changelog

All notable changes to this project are recorded here.

## [1.0.0] - 2026-11

### Added
- Public website: Home, About, Programmes, News with categories and articles, Gallery, Fees, Admissions and Contact.
- Live homepage slider backed by the database and served as JSON by `slides.php`.
- Admissions form and contact form with server-side validation and honeypot spam protection.
- Admin panel for slides, admissions, messages, users and database backup.
- SQLite default database with an optional MySQL schema (`database.sql`).
- `.htaccess` rules protecting configuration and database files.
- Hosting guide for cPanel.

### Documentation
- README, setup guide, database schema, project structure and testing checklist.
